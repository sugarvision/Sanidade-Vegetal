## 📌 Visão Geral da Entrega

Esta entrega formaliza a **Definição de Escopo, Formulação do Problema, Hipóteses Iniciais e Mapeamento de Variáveis de Interesse** para o projeto **Sanidade-Vegetal (SugarVision)**.

O objetivo estratégico do projeto é desenvolver um pipeline preditivo e automatizado capaz de diagnosticar precocemente patologias foliares com ênfase especial na **Ferrugem** (*Puccinia spp.* / *Puccinia melanocephala* / *Puccinia kuehnii*), comparando com tecidos foliares **Saudáveis (Healthy)** e diferenciando de outras doenças concorrentes (*Podridão Vermelha, Mosaico, Mancha Amarela, Escaldadura e Carvão*).
